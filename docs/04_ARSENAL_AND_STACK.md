## 📊 Detailed Technology Taxonomy

### 1. Languages & Systems Programming
- **Python**: Primary language for AI/ML modeling, agent systems, automated pipelines, and backend APIs (`FastAPI`, `Flask`).
- **TypeScript**: Strict-typed full-stack architecture, React/Next.js frontend systems, and secure middleware agents.
- **JavaScript (ES6+)**: Async workflows, DOM manipulation, micro-frontends, dynamic browser extensions.
- **C / C++**: Low-level memory optimization, high-throughput numeric algorithms, algorithmic problem solving.
- **SQL (PostgreSQL & MySQL)**: Relational schema design, ACID transactions, complex aggregations, vector indexing with `pgvector`.

### 2. Autonomous Agents, AI & Machine Learning
- **Agent Orchestration**: `LangChain`, `LangGraph` (stateful cyclical graphs), `CrewAI` (hierarchical swarms), `AutoGPT`.
- **Model Context Protocol (MCP)**: Building bespoke client/server tools connecting local databases and CLI engines to LLMs.
- **Computer Vision**: `OpenCV` (image transformations, contour tracking, thresholding), `MediaPipe` (3D human pose and mesh diagnostics).
- **Deep Learning**: `PyTorch` (custom neural network layers, loss optimization), `TensorFlow` (model deployment).
- **Vector Search & RAG**: `ChromaDB`, `Pinecone`, `FAISS`, `Qdrant`, hybrid dense/sparse keyword fusion.

### 3. Web Architecture & Frontend Engineering
- **Core Frameworks**: `Next.js 15` (App Router, Server Actions, SSR/SSG), `React 19`, `Vite`.
- **Styling & Motion**: `Tailwind CSS`, `Framer Motion`, `Three.js` / `React Three Fiber`, `GSAP`, `Lucide Icons`.
- **State Management & Data**: `Zustand`, `TanStack Query`, `Axios`, `WebSockets`.

### 4. Developer Environments, Tools & Cloud
- **AI-Powered IDEs & Workflows**: `Google Antigravity`, `Cursor`, `Claude Code CLI`, `Cline`.
- **Infrastructure**: `Docker`, `Docker Compose`, `Git`, `GitHub Actions CI/CD`, `Linux CLI`, `Vercel`.
- **API Design & Verification**: `Postman`, `Swagger / OpenAPI`, `cURL`.
